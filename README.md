# Champion's Manager

Tenho um projeto de jogo de gerenciamento de futebol semelhante ao football manager e gostaria de implementar melhorias nele.

Vamos traçar um plano de melhorias que esse projeto precisa para chegar na finalidade dele: um jogo de simulação de treinador de clubes e seleções, com uma vasta database de clubes, ligas, confederações e seleções.
